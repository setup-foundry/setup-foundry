# Setup Foundry

Mit Setup Foundry planen Sie die Einrichtung an Ihrem PC. Sie erstellen einen bootfähigen USB-Stick, der den Installationsablauf
automatisiert. Windows, Programme, Konten und Einstellungen sind beim ersten Login verfügbar.

<img src="bilder/schreibtisch_1600.jpg" alt="Ein Schreibtisch am Abend, darunter schläft ein Berner Sennenhund. Bild von Falzbein, November 2026." width="100%">

[Download](https://www.setupfoundry.com/download) · [Dokumentation](https://www.setupfoundry.com/dokumentation/) · [Editionen](https://www.setupfoundry.com/editionen) · [Webseite](https://www.setupfoundry.com/)

## Funktionen

- Verwendet die offizielle Windows-11-ISO von Microsoft oder eine eigene ISO.
- Installiert Windows unbeaufsichtigt mit einem lokalen Administratorkonto.
- Entfernt unerwünschte vorinstallierte Windows-Apps.
- Wendet vorbereitete Einstellungen für Sicherheit und Datenschutz an.
- Fügt Programme aus dem winget-Katalog zum Installationsmedium hinzu.
- Ermöglicht Ihnen, ohne Vorkenntnisse die Installation sofort auf einer virtuellen Maschine zu testen (Hyper-V oder VirtualBox). Die Einrichtung dafür läuft vollautomatisch.
- Richtet beliebig viele PCs mit einem Installationsmedium gleich ein.

Läuft lokal auf Windows 11 (64 Bit). Benötigt keinen Server, keine Cloud und kein Intune oder Autopilot.
